EaseMotion Dark Mode

Demo showing automatic `prefers-color-scheme` and manual theme switching with CSS variables.

How it works

  • Light mode: default `:root` values
  • Auto dark mode: `@media (prefers-color-scheme: dark)` overrides root values
  • Manual theme: `:root[data-theme="dark"]` / `:root[data-theme="light"]`
Background var(--ease-background)
Surface var(--ease-surface)
Foreground var(--ease-foreground)
Primary var(--ease-primary)

Example CSS

@media (prefers-color-scheme: dark) {
  :root {
    --ease-background: #020617;
    --ease-surface: #111827;
    --ease-foreground: #f8fafc;
    --ease-primary: #60a5fa;
  }
}

:root[data-theme="dark"] {
  --ease-background: #020617;
  --ease-surface: #111827;
  --ease-foreground: #f8fafc;
  --ease-primary: #60a5fa;
}

Theme variables to override

These are the most important tokens for dark mode in an EaseMotion-like system.

  • --ease-background
  • --ease-surface
  • --ease-surface-strong
  • --ease-foreground
  • --ease-muted
  • --ease-border
  • --ease-border-muted
  • --ease-primary
  • --ease-primary-contrast
  • --ease-secondary
  • --ease-shadow
  • --ease-link
